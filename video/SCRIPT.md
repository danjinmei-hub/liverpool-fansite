## 重新生成

```bash
cd video && npm i
# 1. 网站截图与组件截图（需要先在仓库根目录 npm run build:static）
node capture.mjs && node capture2.mjs
# 2. 打包历史动画渲染器
npx esbuild hist-entry.ts --bundle --format=iife --outfile=assets/history.js
# 3. 逐帧渲染（stage.html 是纯时间函数，确定性）
FFMPEG=/path/to/ffmpeg node render.mjs --from=0 --to=30 --out=chunks/c0.mp4   # 分段并行
# 4. 配乐
python3 music.py score.wav
# 5. 合成
ffmpeg -f concat -safe 0 -i list.txt -i score.wav -c:v copy -c:a aac -b:a 192k redchorus-intro.mp4
```
